## Audio

All music, ambience and sound effects are generated live in the browser with the Web Audio API
(`js/systems/audio.js`): oscillators, filtered noise and generated reverb impulse responses.
The music-box lullaby ("Same Shape" theme) is an original composition written for this game.
No audio files from third parties are used, so there are no external audio licences to list.
